# LankaKade admin panel rules

Read the [admin knowledge base](./knowledge-base/README.md) and the guides relevant to your change before editing this project.

- Use React with TypeScript, Tailwind CSS, and Redux Toolkit. Follow the [project structure](./knowledge-base/frontend-architecture.md) and create feature folders as needed.
- Use the [green and white design system](./knowledge-base/design-system.md). Keep color values in the shared theme and use semantic tokens in features.
- Use the shared API client, environment configuration, and feature API modules for requests. Verify the [backend contract and access rules](./knowledge-base/backend-integration.md) before connecting a screen.
- Follow the [engineering standards](./knowledge-base/engineering-standards.md), run the applicable checks, and update the relevant guide when a shared decision changes.
